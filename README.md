## About

I'm **Flild**, a backend developer working primarily with **C#/.NET** and **Python**. I build REST APIs, background processing, integrations, and data workflows.

My repositories cover service-based applications, time-series experiments, and game-server logic. Here are three places to start.

## Selected work

### 01 / [Cosmo Street Food](https://github.com/flild/CosmoStreetFoodEShop)

**E-commerce · Backend services**

A service-based shop with separate product, cart, coupon, email, and authentication services, plus a message bus. REST APIs and EF Core connect the application to PostgreSQL and SQL Server.

**Explore:** service boundaries, messaging, and data access across services. 

`C#` `ASP.NET Core` `EF Core` `PostgreSQL` `SQL Server`

---

### 02 / [AI Market Prediction](https://github.com/flild/AIMarketPrediction)

**Time series · Data workflows**

A Python application that fetches natural-gas futures data, trains an LSTM, and charts historical prices alongside test predictions and a ten-hour forecast.

**Explore:** the path from market data through model training to visualization.

`Python` `TensorFlow` `LSTM` `pandas` `Tinkoff Invest API`

---

### 03 / [Minecraft Curse Cycle](https://github.com/flild/Minecraft-Curse-Cycle)

**Game systems · Server/client synchronization**

A Fabric 1.21.1 mod that introduces a new challenge every five in-game days. The server owns the cycle state, persists it across restarts, and synchronizes challenges to a client HUD and menu.

**Explore:** persistent state, custom network payloads, and server-authoritative logic.

`Java` `Fabric` `Gradle` `CustomPayload API` `PersistentState`

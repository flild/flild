## Selected work

### [CosmoStreetFoodEShop](https://github.com/flild/CosmoStreetFoodEShop)

A small e-commerce system organized as separate services for products, shopping cart, coupons, email, authentication, and a message bus. It uses REST APIs with EF Core across PostgreSQL and SQL Server. The repository also contains a test project.

`C#` `ASP.NET Core` `EF Core` `PostgreSQL` `SQL Server` `microservices`

### [AIMarketPrediction](https://github.com/flild/AIMarketPrediction)

A Python application that fetches natural-gas futures data from the Tinkoff Invest API, trains a two-layer LSTM with dropout, and visualizes historical prices, test predictions, and a ten-hour forecast. It also calculates daily trading results from recent operations.

`Python` `TensorFlow` `LSTM` `pandas` `Tinkoff Invest API`

### [Minecraft-Curse-Cycle](https://github.com/flild/Minecraft-Curse-Cycle)

A Fabric 1.21.1 mod where a server selects a new challenge every five in-game days. The project keeps cycle state across restarts, synchronizes the server-authoritative result to clients, and exposes a HUD plus a paginated menu for active, upcoming, and historical challenges.

`Java` `Fabric` `Gradle` `CustomPayload API` `PersistentState`

## Featured projects

### [CosmoStreetFoodEShop](https://github.com/flild/CosmoStreetFoodEShop)
A multi-service e-commerce application built with C# and .NET. The repository contains separate services for products, shopping carts, coupons, email, and authentication, plus a web application.

**Focus:** service boundaries, REST APIs, Entity Framework Core, PostgreSQL and SQL Server.

### [AIMarketPrediction](https://github.com/flild/AIMarketPrediction)
A Python application that uses an **LSTM neural network** to forecast natural-gas futures prices from historical price and trading-volume data. It visualizes historical values and predictions and calculates trading results.

**Focus:** time-series forecasting, API integration, data preparation, and visualization.
